# CodeAlpha Stock Portfolio Tracker

A simple stock portfolio tracker developed using Python as part of the CodeAlpha Python Programming Internship.

## Features

- Accepts stock names and quantities from the user
- Uses a predefined dictionary of stock prices
- Calculates the investment value for each stock
- Displays the total investment value
- Handles invalid stock names and quantities

## Technologies Used

- Python
- Dictionaries
- Loops
- Conditional statements
- Basic arithmetic
- Input and output

## How to Run

1. Make sure Python is installed.
2. Open the project folder in a terminal.
3. Run:

```bash
python stock_portfolio.py
